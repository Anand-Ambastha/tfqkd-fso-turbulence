# Code of conduct

This project is a research code base. We want discussion of the physics, the numerics and the code to be open, precise and respectful.

**Expected:** be courteous, assume good faith, give specific and constructive feedback, credit other people's work, and accept
corrections to results or derivations as part of normal scientific practice.

**Not acceptable:** harassment, personal attacks, discriminatory language or behaviour, publishing other people's private information,
and any conduct that would be out of place in a professional research setting.

Maintainers may edit, hide or remove contributions that do not follow this code and may block repeat offenders. To report a problem,
open an issue titled "Conduct" without personal details, or contact the maintainer through their GitHub profile.

Adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
